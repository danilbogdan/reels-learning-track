# Reels Learning Track

[English](README.md) | **Русский**

Учебный трек: как научиться снимать короткие вертикальные видео о себе (Instagram Reels, TikTok) и не бросить через неделю.

Идея простая: сначала привычка, потом техника, потом публикации и разбор.

## Принципы

1. Серия важнее качества. В плохой день достаточно голосовой заметки.
2. Первые две недели ничего не публикуем. Цель: привычка и накопленный материал.
3. Идеи берём из чужих удачных роликов: разбираем структуру и переделываем под себя, а не копируем.
4. Решения принимаем по своей аналитике (удержание, досмотры, репосты), а не по общим советам.
5. Монетизация только после стабильных просмотров.

## Недели в двух строках

* **Неделя 1:** 7 дней подряд, заметка + один дубль на 30 секунд.
* **Неделя 2:** хуки и ракурсы, таблица из 20 разобранных роликов.
* **Неделя 3:** первые три публикации.
* **Неделя 4:** 4-5 публикаций, разбор аналитики, вывод по хукам.

## Инструменты

Парный репозиторий [reel-skills](https://github.com/danilbogdan/reel-skills) содержит переиспользуемые навыки для создания рилсов из собственных видео и заметок: разбор референсных роликов и проверка хуков, вырезание пауз и рендер, дайджест голосовых заметок.
