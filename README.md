# Reels Learning Path

Учебный трек: как научиться снимать короткие вертикальные видео о себе (Instagram Reels, TikTok) и не бросить через неделю.

Старт 12 октября 2026, финиш 10 ноября 2026. Идея простая: сначала привычка, потом техника, потом публикации и разбор.

## Принципы

1. Серия важнее качества. В плохой день достаточно голосовой заметки.
2. Первые две недели ничего не публикуем. Цель: привычка и накопленный материал.
3. Идеи берём из чужих удачных роликов: разбираем структуру и переделываем под себя, а не копируем.
4. Решения принимаем по своей аналитике (удержание, досмотры, репосты), а не по общим советам.
5. Монетизация только после стабильных просмотров.

## Недели в двух строках

* **Неделя 1 (12-18 окт):** 7 дней подряд, заметка + один дубль на 30 секунд.
* **Неделя 2 (19-25 окт):** хуки и ракурсы, таблица из 20 разобранных роликов.
* **Неделя 3 (26 окт - 1 ноя):** первые три публикации.
* **Неделя 4 (2-10 ноя):** 4-5 публикаций, разбор аналитики, вывод по хукам.
